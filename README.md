# ContextTalk

Реальный AI-переводчик для живого разговора двух людей с одним телефоном.
Next.js (App Router) + TypeScript. AI: Google Gemini (через абстракцию `AIProvider`).

Как это работает: микрофон → Gemini Live (распознавание) → Context Engine → Gemini (определение языка + перевод с учётом контекста) → Gemini TTS (озвучка голосом нужного человека) → динамик. Подробности: [ARCHITECTURE.md](ARCHITECTURE.md).

## 1. Gemini API key

1. Откройте https://aistudio.google.com/apikey и создайте ключ.
2. Убедитесь, что у проекта есть доступ к моделям `gemini-3.8-flash`, `gemini-3.8-live`, `gemini-3.8-flash-tts` (нужен включённый биллинг, если лимиты бесплатного уровня их не покрывают).

## 2. Локальный запуск

Нужен Node.js 22.6 или новее.

```bash
npm install
cp .env.example .env.local     # впишите GEMINI_API_KEY
npm run dev
```

Откройте http://localhost:3000. `localhost` считается безопасным контекстом, микрофон работает без HTTPS.
Проверка настройки: http://localhost:3000/api/health показывает, виден ли ключ серверу (сам ключ не показывается).

## 3. Vercel

1. Загрузите проект в GitHub и импортируйте репозиторий на https://vercel.com/new.
2. Settings → Environment Variables → добавьте `GEMINI_API_KEY` (для Production, Preview и Development). Остальные переменные необязательны, см. `.env.example`.
3. **Redeploy** (переменные применяются только к новым деплоям).
4. Откройте `https://<проект>.vercel.app/api/health` — должно быть `"geminiKeyConfigured": true`.
5. Откройте сайт **напрямую в Safari/Chrome** (HTTPS обязателен для микрофона).

Важно: маршруты `/api/*` публичны и тратят ваш Gemini-ключ. Встроены проверка origin, лимит запросов и размера, но для публичного запуска включите Vercel Deployment Protection или добавьте авторизацию.

## 5. Как протестировать realtime

1. Откройте сайт на телефоне по HTTPS, нажмите на сферу и разрешите микрофон.
2. В Настройки → «Языки разговора» выберите 2 и более языка. Пара вверху — язык «Я» (слева) и собеседника (справа).
3. Скажите фразу на одном из выбранных языков. Появится перевод и озвучка на язык собеседника.
4. Ответьте на втором языке — перевод вернётся на ваш язык.
5. Пока играет озвучка, начните говорить: звук должен оборваться, статус сменится на «Слушаю».
6. Кнопка «+» вверху начинает новую беседу и очищает контекст.
7. Текстовый ввод (иконка клавиатуры) работает независимо от микрофона и использует тот же перевод.

## 6. Как протестировать клонирование голоса

Настройки → Голоса → «Мой голос» / «Голос собеседника»:

1. «Запишите 10–30 секунд естественной речи» (кнопка «Остановить» активна после 10 с).
2. Прочитайте вслух показанную фразу согласия (на языке профиля).
3. Отметьте подтверждение и нажмите «Создать голос».
4. Дальше перевод на язык этого человека озвучивается его голосом. Без профиля используются два разных встроенных голоса.
5. «Удалить голос» удаляет профиль у Google (при `GEMINI_VOICE_STORE=true`).

Записывайте образец и фразу согласия подряд, в тишине и на одном микрофоне: Google сверяет голос в обоих файлах. При ошибке создания голоса (в т. ч. HTTP 500 от Google) приложение просит перезаписать оба шага заново.

## 7. Ограничения (preview/beta)

- Voices API (клонирование голоса) — бета. Живые клонированные голоса поддерживаются только TTS-моделью, а не Live API, поэтому озвучка идёт через `gemini-3.8-flash-tts`.
- TTS отдаёт аудио целиком по каждому предложению (не потоком), поэтому перевод режется на предложения, и озвучка начинается с первого.
- Live-сессия используется как «уши» (транскрипт). Если Live недоступен, приложение отправляет аудио реплики напрямую в Gemini для транскрипции и перевода.
- Эхо динамика может ложно перебивать озвучку на некоторых устройствах: включены echoCancellation и повышенный порог перебивания; если мешает, используйте наушники.
- Формат Live-сессии для `gemini-3.8-live` собран по документации и должен быть проверен на вашем ключе (см. ARCHITECTURE.md, раздел «Что требует проверки»).

## 8. Приватность

- Аудио не сохраняется: фрагмент текущей реплики уходит в запрос и забывается; образцы голоса существуют только в памяти до отправки.
- В браузере хранятся только текст истории, контекст и идентификаторы голосов (`localStorage`).
- `GEMINI_API_KEY` используется только в `app/api/*`; браузер получает одноразовый токен Live.
